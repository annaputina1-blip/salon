# Telegram-бот для записи

Бот работает внутри `server.js` и использует polling Telegram Bot API. Отдельный процесс запускать не нужно: достаточно `npm start`.

## Что нужно заполнить в `.env`

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=chat_id_мастера_для_уведомлений

BOOKING_WORKDAY_START=09:00
BOOKING_WORKDAY_END=20:00
BOOKING_DAYS_AHEAD=14
BOOKING_SLOT_STEP_MINUTES=30
BOOKING_TIMEZONE_OFFSET=+03:00
```

`TELEGRAM_CHAT_ID` нужен, чтобы мастеру приходили уведомления о новых записях. Клиенты могут писать боту без указания своего chat id.

## Как клиент записывается

1. Нажимает `/start`.
2. Выбирает направление: лазерная эпиляция или LPG-массаж.
3. Выбирает услугу с ценой.
4. Выбирает дату и свободный слот.
5. Оставляет имя.
6. Оставляет телефон в формате `+7 918 421 44 94`.

Бот показывает только свободные окна. Перед сохранением запись повторно проверяется, поэтому пересечения по времени не создаются.

## Где хранятся записи

Записи сохраняются в `data/appointments.json`, а копия заявки добавляется в `data/requests.json` с источником `telegram_bot`. В админке записи отображаются отдельным блоком.

## Команды бота

- `/start` или `/book` - начать запись.
- `/services` - посмотреть услуги и цены.
- `/appointments` - посмотреть ближайшие записи, доступно только чату мастера из `TELEGRAM_CHAT_ID`.
- `/cancel` - отменить текущий диалог записи.
